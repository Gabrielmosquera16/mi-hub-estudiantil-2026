# Mi Hub Estudiantil 2026

Mini-sitio individual desarrollado para la **Tarea Práctica #2: Integración HTML y CSS / Control de versiones** del curso Desarrollo Web.

## Autor

**Gabriel Oriel Mosquera Magallón**

## Estructura

```text
.
├── index.html
├── recursos.html
├── css/
│   └── estilos.css
└── img/
    └── avatar-gabriel-web.png
```

## Características

- Dos páginas HTML semánticas y navegación entre ellas.
- Hoja de estilos CSS externa con variables, estados hover, Grid/Flexbox y diseño responsive.
- Perfil académico, intereses, meta del semestre, recursos de aprendizaje y trayectoria de asignaturas.
- Formulario de muestra, solo maquetado y sin backend.

## Vista local

Abra `index.html` en un navegador o sirva la carpeta con un servidor estático, por ejemplo:

```bash
python3 -m http.server 3000
```

El sitio no recopila datos ni requiere dependencias externas.
